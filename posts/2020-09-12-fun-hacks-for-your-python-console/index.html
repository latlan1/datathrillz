Fun Hacks for your Python Console

September 12, 2020 · 2 min

Hack #1: Color Text in Your Terminal #

You can change the colors of text shown in your Python terminal console using ANSI escape character sequences! Or you can use the colorama library to make the process a bit easier and more streamlined. Colorama works across all the platforms i.e. Windows, Mac OS and Unix.

First, we import the modules that we need from colorama. [code] from colorama import Fore, Back, Style [/code]

Next, we can specify the foreground and background colors of any text. We can combine the effects by using a plus sign with the Fore, Back and/or Style modules.

Here are all of the options for foreground and background colors and styles of text printed to the console. [code] Fore: BLACK, RED, GREEN, YELLOW, BLUE, MAGENTA, CYAN, WHITE, RESET. Back: BLACK, RED, GREEN, YELLOW, BLUE, MAGENTA, CYAN, WHITE, RESET. Style: DIM, NORMAL, BRIGHT, RESET_ALL [/code]

Alternatively, we could use the cprint function from the termcolor library to print colored text. The syntax is a bit easier to use.
